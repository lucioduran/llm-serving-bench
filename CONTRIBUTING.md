# Contributing

Use English, focused commits and regression tests. Run the README checks before
opening a pull request. Keep protocol, metric and methodological decisions in docs.
Do not replace observed measurements with simulated timings. New evidence needs
actual hardware, model revision, software versions, requests, raw arrivals and
explicit limitations. Run only free local inference; serialize heavy jobs with
the coordinator lock in the original project series. Do not publish credentials,
private prompts or downloaded model weights. No human review is claimed by the
initial release.
